Semblance™ Issues
=================

This public repository is used only for reporting and tracking issues with
Semblance™.

Please use the issue-report form built into Semblance™ whenever possible. It
collects the application version, operating system, problem category, expected
behavior, actual behavior, and reproduction steps before opening GitHub's final
review page.

Before submitting an issue:

1. Remove passwords, license keys, personal information, and other sensitive
   data.
2. Review any diagnostic log before attaching or pasting it. Logs may contain
   local file paths and exception details.
3. Include the smallest model or project that reproduces the problem when the
   file can be shared publicly.
4. Use one issue for each distinct problem.

Semblance™ application repository:
https://github.com/Criterion-Labs/Semblance
